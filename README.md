# 屏幕区域变化检测截图器

捕获屏幕/窗口,框选一个区域,区域出现**显著状态变化**时自动截图,打包 zip 下载。

## 启动

1. 确保已装 Node.js(https://nodejs.org)
2. 双击 `start.bat`
3. 浏览器自动打开 `http://127.0.0.1:5173`

> 必须通过 localhost 访问。屏幕捕获 API(`getDisplayMedia`)在 `file://` 下被浏览器禁用。

## 用法

1. 点【选择屏幕】→ 浏览器弹窗选要共享的屏幕/窗口/标签
2. 在预览画面上**拖一个矩形框**,圈住要监控的区域
3. 点【开始监控】
4. 区域出现显著变化 → 自动截图,加入右侧列表
5. 【暂停】临时停手;【立即截图】手动补一张;【停止】结束
6. 点【导出 zip】下载全部截图

截图命名:`change_001_12.3s.png`(序号 + 距监控开始的秒数)。

## 检测原理

**上升沿触发(无冷却)** —— 逐次捕获短时间内的多次变化,不漏截:

- 每隔「采样间隔」抓一帧区域,与上一帧比「变化像素比例」
- 比例 > 高阈 → 检测到变化,**立刻截一张**,进入「变化中」
- 「变化中」期间不重复截(同一变化只截一次)
- 比例 < 低阈(变化结束)→ 回到待命,准备捕获下一次变化
- 无冷却:短时间内连续多次变化都能逐次截到

## 参数说明(右侧面板可调)

| 参数 | 默认 | 说明 |
|---|---|---|
| 采样间隔 | 150ms | 多久抓一帧比较 |
| 像素差阈值 | 30 | 单像素 RGB 差超过此才算「该像素变了」 |
| 变化比例高阈 | 3% | 超过判定显著变化,立刻截一张 |
| 变化比例低阈 | 0.5% | 低于判定「变化结束」,允许下一次触发 |

## 边界(必读)

- **持续大幅运动的区域**(变化像素比例一直高于高阈、不回落)只会在第一次变化时截一张,之后不再触发(因为一直停在「变化中」)。应对:调高高阈,或用【暂停】手动控。
- **渐变切换**截的是「变化刚开始的那一帧」,可能略带过渡。想要更稳的画面,调高「变化比例高阈」让它只在变化剧烈时触发。
- 每次启动浏览器会弹屏幕共享权限,这是浏览器规范,无法绕过。
