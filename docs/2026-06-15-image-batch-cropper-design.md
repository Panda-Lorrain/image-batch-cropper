# 截图批量框选裁切工具 — 设计文档

- 日期: 2026-06-15
- 状态: 设计已确认,待 spec 审阅
- 产出: brainstorming 会话

## 1. 背景与目标

用户经常处理大量截图(默认存放于 `C:\Users\26875\Pictures\Screenshots`),需要按统一的区域规则批量裁切(例如统一截取画面中的某个面板、统一去掉某条边)。逐张手动裁切繁琐。

本工具提供一个**纯本地网页**:导入一批截图 → 在一张样图上拖出裁切框 → 一键把同一选区套用到所有图 → 打包成 zip 下载。所有处理在浏览器本地完成,图片**不上传任何服务器**。

**成功标准**:导入 N 张截图,拖一次框,点一次按钮,得到 N 张按同一选区裁好的图(打包 zip),文件名与原图一致(重名自动去重)。

## 2. 需求

### 2.1 功能需求

- **F1 批量导入**:支持拖入页面、点按钮多选文件、选文件夹三种方式导入图片(png / jpg / jpeg / webp)。
- **F2 样图拖框**:在第一张图(或用户切换到的任一张)上用鼠标拖出矩形选区。
- **F3 选区调整**:选区可通过 8 个手柄拖拽改变位置与大小,方向键做像素级微调。
- **F4 选区反馈**:实时显示选区的**原图像素坐标** (x, y) 与尺寸 (w, h)。
- **F5 样图切换**:可切换查看不同导入图,核对选区在不同图上的普适性;缩略图条显示全部导入图。
- **F6 预览裁切**:可预览当前选区套用到样图的裁后效果。
- **F7 批量裁切 + zip 下载**:一键把同一选区套用到全部导入图,打包 zip 下载;进度条显示处理张数。
- **F8 比例锁定(可选)**:拖框时可锁定固定比例(自由 / 1:1 / 16:9 / 4:3)。

### 2.2 非功能需求

- **NF1 零安装**:双击 `index.html` 用浏览器打开即用,无需 npm / pip / 构建。
- **NF2 离线可用**:所有依赖(含 JSZip)本地内联,断网也能用。
- **NF3 跨浏览器**:不依赖 File System Access API,任意现代浏览器(Edge / Chrome / Firefox / Safari)均可。
- **NF4 隐私**:图片全程不离开本地浏览器。
- **NF5 性能**:能处理上百张截图,单张裁切 < 100ms,UI 不卡顿(批量裁切分片到 `requestIdleCallback` 或分批 `setTimeout`,避免阻塞主线程)。

### 2.3 范围外(YAGNI)

- 不做逐张微调流程(本期统一套用)。
- 不做多模板分批。
- 不做写本地文件夹(FSA)——本期 zip 下载。
- 不做智能识别 / 自动裁白边。
- 不做图片旋转 / 缩放 / 标注编辑。
- 不做服务端、账号、云存储。

## 3. 技术选型

- 纯原生 HTML5 + CSS + JavaScript(ES2020),**无框架、无构建**。
- Canvas 2D API 做选区渲染与裁切。
- `FileReader` / `URL.createObjectURL` 读取图片。
- **JSZip 3.10.1**(MIT 许可,本地内联于 `vendor/`)打包 zip。
- 不依赖 File System Access API。

## 6. 交互流程

1. **导入**:拖图进页面 / 点"导入图片"多选 / 点"选文件夹"批量导入。非图片文件自动跳过。
2. **拖框**:第一张图作为样图显示在画布。鼠标按住拖出矩形框。
3. **调整**:拖 8 个手柄改大小、拖框体改位置;方向键像素级微调;右侧实时显示坐标与尺寸。
4. **核对**:用 `>` `<` 切换样图,确认选区在其他图上也合适;缩略图条可点选任意张。
5. **预览**:点"预览裁切"查看当前选区套用到样图的裁后效果。
6. **导出**:点"裁切全部并保存" → 全部图按同一选区裁切 → 打包 zip 下载。进度条显示 `已处理 i / N`。

## 7. 核心组件设计

每个组件职责单一、接口明确、可独立理解与测试。

### 7.1 ImageList — 导入图片管理

- **职责**:维护导入图片列表、当前样图索引、缩略图。
- **接口**:
  - `addFiles(files: File[]): void` — 过滤非图片后追加。
  - `getCount(): number`
  - `getAll(): { file: File, name: string, url: string, natW: number, natH: number }[]`
  - `getCurrent(): Item | null`
  - `setCurrent(index: number): void`
  - `next(): void` / `prev(): void`
- **依赖**:无(纯数据管理)。内部用 `URL.createObjectURL` 生成预览 URL,加载后读取自然尺寸 `natW/natH`。

### 7.2 CropCanvas — 选区拖框交互

- **职责**:在 canvas 上渲染当前样图 + 选区框 + 8 手柄,处理鼠标/键盘交互,输出选区。
- **接口**:
  - `load(item: Item): void` — 载入样图并计算 fit 缩放比 `scale`。
  - `getSelection(): { x: number, y: number, w: number, h: number }` — **原图像素坐标**。
  - `setSelection(rect): void`
  - `setAspectLock(ratio: number | null): void`
- **关键**:鼠标事件坐标 ÷ `scale` = 原图坐标;选区始终以原图像素坐标存储,与显示缩放解耦,保证裁切精度。
- **依赖**:DOM `<canvas>`、ImageList(取当前样图)。

### 7.3 Cropper — 单张裁切(纯函数)

- **职责**:输入图片源 + 选区 → 离屏 canvas 裁切 → 输出 Blob。
- **接口**:
  - `crop(src: HTMLImageElement | ImageBitmap, sel: Rect, mimeType: string, quality?: number): Promise<Blob>`
- **依赖**:无(纯函数 + 离屏 canvas)。保持原 MIME:png → `image/png`,jpeg → `image/jpeg`。

### 7.4 Namer — 命名与重名去重

- **职责**:生成输出文件名,默认保持原名;遇重名自动去重。
- **接口**:
  - `makeName(originalName: string, used: Set<string>): string`
- **规则**:原名优先;若 `used` 中已存在,在扩展名前追加 `_1`、`_2`... 直到唯一(如 `截图1.png` → `截图1_1.png`)。返回新名并加入 `used`。

### 7.5 Exporter — 批量裁切 + zip 下载

- **职责**:遍历全部图,逐张 Cropper 裁切 + Namer 命名 → JSZip 打包 → 触发下载。
- **接口**:
  - `exportAll(list: ImageList, sel: Rect, onProgress: (i, n) => void): Promise<ExportReport>`
- **流程**:`for each item: blob = crop(item, sel); name = Namer.makeName(item.name, used); zip.file(name, blob); onProgress(...)` → `zip.generateAsync` → 触发 `<a download>`。
- **分片**:每处理一张让出主线程(分批 `setTimeout`),避免上百张时 UI 卡死。
- **依赖**:Cropper、Namer、JSZip。
- **ExportReport**:`{ total, success, failed: [{name, error}], renamed: [{from, to}] }`。

### 7.6 主控制器(app.js)

- **职责**:实例化上述组件,绑定 DOM 事件(导入、拖框、切换、预览、导出),协调状态。
- **依赖**:全部组件。

## 8. 数据流

```
File[] ──导入──▶ ImageList
                   │
                   ▼ 取当前样图
              CropCanvas ──用户拖框──▶ selection {x,y,w,h} (原图坐标)
                   │                          │
                   │                          ▼
                   │            (预览: Cropper.crop(样图, sel) → 显示)
                   │                          │
                   └────── 点"导出" ──────────▼
                                   Exporter.exportAll(list, sel, onProgress)
                                     │  遍历每张:
                                     │   blob = Cropper.crop(item, sel, mime)
                                     │   name = Namer.makeName(item.name, used)
                                     │   zip.file(name, blob)
                                     ▼
                              zip.generateAsync → Blob → <a download>.click()
                                     │
                                     ▼
                              ExportReport(成功/失败/改名汇总)
```

## 9. 关键决策与默认值

| 决策点 | 取值 | 理由 |
|---|---|---|
| 裁切语义 | 保留框内 | 标准裁切语义 |
| 选区坐标系 | 原图像素坐标 | 与显示缩放解耦,保证精度 |
| 应用方式 | 统一套用(拖一次框) | 截图场景最常见,交互最简 |
| 输出形态 | zip 打包下载 | 跨浏览器、零授权、简单 |
| 输出命名 | 保持原名;重名追加 `_1/_2` | 用户指定;去重防覆盖 |
| 输出格式 | 保持原格式(png/jpeg) | 不引入额外转换 |
| 覆盖原图 | 否 | 安全;原图不动 |
| 比例锁 | 默认自由,可选锁定 | F8 可选增强 |

## 10. 错误处理

| 场景 | 处理 |
|---|---|
| 导入非图片文件 | 跳过,提示"已忽略 N 个非图片文件" |
| 选区零面积 / 越界 | 禁用"裁切全部"按钮,提示"请先拖出有效选区" |
| 某张图尺寸与样图不同 | 套用同选区前提示"第 N 张尺寸与样图不同,选区可能偏移",允许继续 |
| 某张裁切失败 | 记入 `failed`,继续处理其余,最终汇总 |
| 重名文件 | Namer 自动追加 `_1/_2`,记入 `renamed`,汇总提示 |
| JSZip 加载失败 | 启动时检测 `window.JSZip`,缺失则页面顶部红条提示"依赖加载失败,请用本地打开方式" |

## 11. 测试与验收

本地网页工具无自动化框架。在 README 提供手动验收清单:

- **正常**:同尺寸 PNG 截图 10 张 → 拖框 → 导出 → zip 内 10 张,命名与原图一致,裁切区域与预览一致。
- **混合格式**:png + jpg 混合导入 → 各自保持原格式输出。
- **重名**:导入两个同名 `截图1.png` → zip 内 `截图1.png` + `截图1_1.png`,汇总列出改名项。
- **尺寸不一致**:混入一张分辨率不同的图 → 触发偏移警告,仍可导出。
- **边界**:零选区时按钮禁用;超大图(>4000px)自动 fit 显示,裁切仍精确。
- **浏览器回退**:在 Firefox / Safari 打开,导出 zip 正常(不依赖 FSA)。
- **离线**:断网后双击打开,全部功能正常(JSZip 本地内联)。
- **规模**:100 张图导出,进度条正常推进,UI 不卡死。
